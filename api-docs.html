Aachico Vault API दस्तावेज़

अपने ट्रांसपोर्ट बिजनेस सिस्टम को हमारे फ्लीट मैनेजमेंट ओएस के साथ जोड़ने के लिए सुरक्षित REST API एंडपॉइंट्स।

1. प्रमाणीकरण (Authentication)

सभी एपीआई अनुरोधों के लिए हेडर में एक वैध Bearer Token का होना अनिवार्य है। आप अपने एडमिन डैशबोर्ड से API Key जनरेट कर सकते हैं।

Authorization: Bearer YOUR_AACHICO_API_KEY

2. ट्रिप डेटा प्राप्त करें (Get Trips API)

फ्लीट की लाइव ट्रिप प्रविष्टियों और बिलिंग विवरण को प्राप्त करने के लिए निम्नलिखित एंडपॉइंट का उपयोग करें:

GET https://api.aachicoinfotech.com/v1/vault/trips

3. तकनीकी सहायता

यदि आपको कस्टम इंटीग्रेशन या वेबहुक कॉन्फ़िगरेशन में कोई सहायता चाहिए, तो आप सीधे हमारे उदयपुर कार्यालय की तकनीकी टीम से संपर्क कर सकते हैं।
